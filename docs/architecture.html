Workflow · a booking being made

The public path, which is the most exposed code in the product. Note that payment confirmation is pull-based — the server re-fetches the order rather than trusting anything the browser reports.

Workflow · code reaching production

Manual by necessity: GitHub Actions is billing-blocked, so every run reaches startup_failure with zero jobs executed. The dashed branch is what should happen and currently does not.

Single point of failure

PostgreSQL

One container, no replica, no failover, and backups never verified restorable — it sits on the same floor as everything else in LXC 110. Every other component can be rebuilt and re-pulled from GHCR in minutes. This one cannot.

Drawn from the repository at merge commit ce06d78. Verified against production: five containers up, disk 38% of 16 GB, 473 tests passing.
